# 狐狸谷物语 - 项目策划文档

> 最后更新：2026-07-29

## 一、项目概述

- **项目名称**：小狐大世界（Fox Hollow Tales）
- **类型**：增量放置 / 村庄建设
- **灵感来源**：Kittens Game（猫国建设者），玩法机制相似，但所有文案、命名、主题完全原创
- **主题**：玩家经营一个狐狸山谷村落，从采集野莓开始，逐步建造设施、吸引村民、发展科技
- **风格**：白底黑字纯文字界面，紧凑单行排版
- **线上地址**：https://akira17189-create.github.io/fox-hollow/（GitHub Pages，推送后自动更新；旧地址 https://2d9lpj7e.mule.page/）

|------|------|------|------|

### 2.7 季节系统

每年4个季节循环，每季 100 天（游戏内时间）。

| 季节 | 野莓产量倍率 | 特殊效果 |
|------|-------------|----------|
| 早春 | ×1.5 | 丰收季 |
| 盛夏 | ×1.0 | 正常 |
| 金秋 | ×1.2 | 略丰 |
| 寒冬 | ×0.25（庇护后×0.4） | 产量骤降，需提前囤粮 |

### 2.8 满意度系统

- 基础值：100%
- 人口 > 5 时，每多1只狐狸 -2%
- 灵狐祠每座 +5%
- 研究「狐灵传说」+10%
- 范围：10% ~ 200%
- 影响手动采集野莓的产量
- 影响全体职业产出（乘以满意度百分比）
- 悬浮面板显示计算明细及当前职业产出倍率

### 2.9 人口系统

- 狐狸通过「狐狸窝」提供容量（每座+2）
- 当容量有余且野莓 > 20 时，有 1.5% 概率每 tick 迁入新狐狸
- 研究「先祖之眼」后狐狸消耗野莓 -15%（0.35→0.30/s）
- 野莓耗尽时，每 50 tick 有一只狐狸离开
- 每只狐狸消耗野莓 0.35/s

### 2.10 事件系统

#### 山谷见闻
- 25 种随机事件，约每 10 分钟触发一次（概率 0.0003/tick）
- 四大类：灵启（需灵狐祠）、天象、山谷异象、过客与声音
- 加权随机选取，部分有季节/建筑前置条件
- 部分事件附带资源奖励

#### 世界的回响
- 18 段极稀有叙事文本，约每 3 小时触发一次（概率 0.00002/tick）
- 按季节分类（春4/夏5/秋5/冬4），仅当前季节可触发
- 斜体蓝灰色显示，与普通日志区分
- 纯叙事，无资源效果

### 2.11 存档系统

- **自动存档**：localStorage，每 30 秒自动保存
- **手动存档**：Header「存档」按钮
- **存档码**：Base64 编码导出/导入，支持跨设备迁移
- **后台补算**：切换标签页再切回时，自动补算离开期间的资源产出（含季节更替、狐狸消耗、饥荒、迁入）
- 最大补算时间 24 小时

## 三、UI 设计

- **风格**：白底黑字，纯文本，无图标无装饰
- **布局**：三栏（左：资源 | 中：操作 | 右：日志）
- **建筑行**：单行紧凑「名称 (数量) 费用 [建造] [出售]」
- **费用不足**：红色高亮
- **Tab**：营火 / 村落 / 工坊 / 研究

### 3.1 悬浮信息面板

所有游戏元素名称支持鼠标悬停显示信息面板（`position: fixed`，JS 定位防溢出）：
- 建筑：描述 + 效果数值 + 解锁提示 + 短句
- 职业：描述 + 每人产出 + 短句
- 研究：描述 + 加成百分比 + 短句
- 工坊：描述 + 短句
- 资源：短句 + 特殊提示
- 满意度：显示计算明细

### 3.2 短句系统

- 数据中以 `tip` 数组存储，支持多句
- 每季缓存一次，季节更替时刷新
- 风格：冷幽默、有哲思、克制、口语化

### 8.1 设计理念

猫国建设者的核心乐趣是计算最优路径；小狐大世界的差异化在于**叙事驱动的好奇心**。远行系统的核心不是"去换资源"，而是"去听故事"——每次远行返回带来叙事碎片，逐步拼出更大的世界观。

- **「山外」Tab**：解锁条件为研究「山外见闻」完成
- 包含：远行面板、商队面板、叙事碎片收集

| 瞭望塔 | 砖块8, 矿铁5, 圆木20（×1.12） | 远行时间 -15%/座（乘法叠加）；香料上限+3, 丝帛上限+5, 古币上限+3；被动消耗符咒 | 驿道×1 |

**瞭望塔符咒维持**：引擎 tick 速率 `charmP: -0.01`，显示 -0.005/s，实际消耗 **1.0 符咒/季**。1 座灵狐祠产出 1.2/季，可供养 1 座瞭望塔并略有盈余。

**瞭望塔失效机制**：新增辅助函数 `activeWatchtowers()`，返回当前有效的瞭望塔数量。判定逻辑：若 `G.res.charm.v <= 0` 且瞭望塔的 charmP 消耗使净符咒产量为负，则返回 0（全部失效）；否则返回 `G.bld.watchtower.c`。所有使用瞭望塔效果的地方（远行时间计算、远行面板显示）统一调用此函数，而非直接读 `G.bld.watchtower.c`。瞭望塔的资源上限效果（spiceMx/silkMx/ancCoinMx）不受失效影响，仅远行时间减免失效。不中断进行中的远行。

### 8.7 远行系统

#### 操作流程

1. 在「山外」Tab 选择目的地
2. 消耗资源（野莓干粮 + 铜钱路费 + 符咒灵力）
3. 派出 1-3 只闲置狐狸（锁定为外出状态）
4. 等待游戏内天数倒计时
5. 返回：获得资源奖励 + 随机返回日志；旧墟/云岭另附带一段叙事碎片

#### 远行记录结构

`G.expeditions` 数组，每条记录：

```
{
  dest: string,          // 目的地 ID（nearHill / forest / oldRuin / cloudRidge）
  foxCount: number,      // 派出狐狸数
  ticksLeft: number,     // 剩余 tick 数
  totalTicks: number,    // 总 tick 数（用于进度条计算）
  usedSpiritPath: boolean // 是否已对此次远行施放过灵路
}
```

#### 目的地

| 目的地 | 路程 | 消耗 | 解锁条件 |
|--------|------|------|----------|
| 旧墟 | 30天 | 野莓50, 铜钱2 | 驿道×1 |
| 云岭 | 60天 | 野莓100, 铜钱5, 符咒1 | 驿道×1, 瞭望塔×1, 研究：远途跋涉 |
| 荒丘 | 100天 | 野莓200, 铜钱8, 符咒4 | 驿道×3, 瞭望塔×1 |
| 密林 | 150天 | 野莓300, 铜钱10, 符咒8 | 驿道×3, 灵狐祠×2 |

路程受瞭望塔缩减：每座 ×0.85（2 座 = ×0.72，3 座 = ×0.61）。

#### 奖励池

每次返回从目的地奖励池抽取 2-3 项，数量 = 基础数量 × (1 + 斥候数 × 0.2) × (研究「远途跋涉」? 1.5 : 1)。

| 目的地 | 奖励池（基础数量） |
|--------|-------------------|
| 旧墟 | 矿铁 3-6, 古币 1-2, 遗光 1（10%概率），叙事碎片（必定） |
| 云岭 | 符咒 3-5, 古币 2-3, 叙事碎片（必定） |
| 荒丘 | 碎石 10-20, 兽皮 1-3, 香料 1（40%概率） |
| 密林 | 圆木 15-25, 兽皮 2-4, 丝帛 1（40%概率） |

旧墟和云岭每次必定返回一段叙事碎片（按顺序推进，不重复抽取）。

#### 抉择事件

斥候 ≥ 2 时，远行返回有概率触发抉择事件。玩家从 2 个选项中选择，不同选项导致不同后果（资源变化、新事件加入事件池、特殊状态等）。无最优解。

已实装 5 个抉择事件（刻名墙/南迁之问/石标修缮/掌印墙/旧墟老狐狸），每个含 2 个选项与不同后果。

#### 叙事碎片收集状态

已收集的叙事碎片以 `G.narratives` 持久化：

```
G.narratives = {
  oldRuin: [],      // 已解锁的旧墟碎片索引数组，如 [0, 1, 2]
  cloudRidge: []    // 已解锁的云岭碎片索引数组
}
```

远行返回时，取 `G.narratives[dest].length` 作为下一条碎片的索引，若未超出数据总条数则推入。山外 Tab"叙事碎片"区域按序展示已收集条目，未收集的显示为"???"占位。

#### 外出狐狸状态

- 新增 `G.foxAway` 追踪外出狐狸数
- 派出时：`G.foxAway += n`，`G.freeFox -= n`
- 返回时：`G.foxAway -= n`，`G.freeFox += n`
- 外出狐狸**不消耗村内野莓**（出发时已扣干粮）
- 外出狐狸**不受饥荒减员影响**
- 野莓消耗计算用 `G.foxes - G.foxAway`
- `rmFox()` 只从村内狐狸（含职业和闲置）中移除

### 8.8 商队系统

外来商队为其他物种的狐族或山谷中的灵兽，周期性到访。

#### 机制

- 每 2-3 个季节随机有商队到访，停留 1 个季节后离开
- 到访时日志提示，「山外」Tab 显示商队商品
- 每种商品每次驻留可购买 1 次
- 冷却追踪：`G.caravanTimer`（整数），每次季节更替 +1；商队离开时重置为 0；当 `caravanTimer >= 2` 时每季有 50% 概率到访（保证间隔 2-3 季）；商队在场时不计数

#### 商队类型

| 商队 | 商品 A | 商品 B | 收购（玩家卖出换铜钱） | 出现条件 |
|------|--------|--------|----------------------|----------|
| 山猫行商 | 香料×2 = 铜钱8 | 兽皮×3 = 铜钱5 | 圆木30 → 铜钱3 | 默认 |
| 河獭商队 | 丝帛×2 = 铜钱10 | 矿铁×3 = 铜钱8 | 木板2 → 铜钱5 | 瞭望塔×1 |
| 白鹤信使 | 卷轴×2 = 铜钱12 | 符咒×2 = 铜钱10 | 砖块3 → 铜钱5 | 灵狐祠×1 |
| 旧墟遗民 | 古币×2 = 铜钱15 | 符咒×3 = 铜钱12 | 不收购 | 远行旧墟完成≥1次 |

4 种商队均已配置到访/离开日志文案。

### 8.9 灵术扩展

新增 2 个灵术 + 1 个宴席机制：

| 灵术/机制 | 消耗 | 效果 | 限制 |
|-----------|------|------|------|
| 灵路 | 符咒6 | 当前进行中的一次远行剩余时间 -30% | 每次远行限用一次 |
| 商风 | 符咒10 | 立即召来一支随机商队（停留1季） | 每年限一次；已有商队在场时不可施放 |
| 山谷宴席 | 香料2, 野莓100 | 满意度 +15%，持续本季 | 每季限一次；需驿道×1 |

灵路在叙事框架中的含义：灵力引导，此次远行有概率触发更深层叙事。

**灵路目标选择**：若仅 1 支队伍在外，自动对其施放；若多支队伍同时在外，默认对剩余时间最长（ticksLeft 最大）的队伍施放。按钮显示目标目的地名，如"灵路（→旧墟）"。若所有在外队伍均已使用过灵路，按钮置灰。

商风状态追踪：`G.tradeWindYear`，当年施放过则不可再施放。已有商队时按钮置灰显示"（商队在场）"。

宴席状态追踪：`G.feastSeason`，当季施放过则不可再施放。`calcH()` 中 `if (G.feastSeason === G.season) h += 0.15`。

### 8.11 离线补算

`simulateOffline()` 新增：

- **远行倒计时推进**：每 tick 减少剩余天数，到期自动结算奖励（静默，不输出叙事）
- **返回提示**：回到游戏时日志显示"离开期间，远行队伍从 [目的地] 返回了。"（附奖励清单）
- **叙事暂存**：离线期间完成的远行，叙事碎片存入 `G.pendingNarr` 队列，回到游戏后逐条展示
- **商队到期**：离线期间商队停留时间耗尽则自动离开
- **瞭望塔维持**：离线期间符咒持续扣除，不足时瞭望塔标记失效

### 8.12 解锁检查扩展

`chk()` 新增条件类型 `q.exp`，检查远行完成历史：

- 状态追踪：`G.expDone = { nearHill: 0, forest: 0, oldRuin: 0, cloudRidge: 0 }`（完成次数）
- 示例：研究「远途跋涉」的 `uq: { b: { trailroad: 2 }, exp: { oldRuin: 1 } }`
