- **新 Tab「山外」**：研究「山外见闻」后解锁，包含远行面板、商队面板、叙事碎片收集
- **新资源**：香料、丝帛、古币（贸易分类，上限由驿道/瞭望塔提供）
- **新建筑**：
  - 驿道：解锁远行，提供贸易资源上限
  - 瞭望塔：远行时间 -15%/座（乘法叠加），持续消耗符咒维持
- **新职业 · 斥候**：无被动产出，每人使远行奖励 +20%，≥2 人时远行可触发抉择事件
- **新研究**：山外见闻（解锁山外 Tab）、远途跋涉（远行奖励 +50%，解锁云岭）
- **远行系统**：选择目的地 → 消耗资源 → 派出 1-3 只狐狸 → 等待天数倒计时 → 返回获得奖励 + 叙事碎片
- **4 个远行目的地**：旧墟、云岭、荒丘、密林（天数/消耗/解锁递增）
  - 旧墟和云岭带有完整叙事线（10 + 8 段叙事碎片）
- **商队系统**：4 种外来商队周期到访，提供贸易资源交易
- **灵术扩展**：灵路（远行加速 -30%）、商风（召唤商队）、山谷宴席（满意度 +15%）
- **离线补算**：覆盖远行倒计时、商队到期、叙事暂存

### v0.11.1 - 远行 Bug 修复与体验优化
- **斥候数量选择修复**：原生 `<select>` 下拉框因 DOM 重建无法操作，改为按钮组 `[1只] [2只] [3只]`
- **自动制作资源停滞修复**：
  - 连续速率模型增加 95% 消耗上限，防止自动制作吃掉 100% 的输入产量导致资源不动
  - 输入产量为零时启用储备慢速模式（25% 速度），储备 ≥ 3 倍配方消耗时才执行
- **自动制作速率显示修正**：UI 直接读取引擎计算的实际速率（`G._acRates`），不再反推理论值
- **自动制作暂停原因修正**：区分「原料不足」和「产出已满」两种暂停状态（`G._acStop`）

### v0.11.2 - 远行目的地调序与文案
- **解锁顺序调整**：旧墟（有叙事）和云岭（有叙事）优先解锁，荒丘和密林（暂无叙事）推后
- **天数/消耗/解锁递增**：
  - 旧墟 30 天 → 云岭 60 天 → 荒丘 100 天 → 密林 150 天
  - 消耗从 野莓50+铜钱2 递增至 野莓300+铜钱10+符咒8
  - 解锁从 驿道×1 递增至 驿道×3+神祠×2
- **近丘改名荒丘**：原名「近丘」放在第三位有违和感，改为「荒丘」，日志文案同步更新
- **旧墟/云岭添加描述与短句**：悬停目的地名称显示地点描述、奖励预览和风格化短句
- **更新 design.md**：目的地表格、奖励池、资源获取途径同步更新

### v0.12.0 - 图纸与专精
- **图纸系统**：商队到访时 50% 概率携带图纸，可购买后在工坊 Tab 激活
  - 图纸为具名物品，同一目标的 A/B 方向互斥持有
  - 激活时自动丢弃同目标其他方向的图纸
  - 图纸仅在玩家拥有对应资源上限时才会生成
- **建筑专精**（8 种，需建筑 ≥5 座 + 图纸激活，不可撤销）：
  - 莓果园：沃土（产量+40%，造价+25%）/ 野蔓（造价-20%，产量+10%）
  - 伐木场：深林（圆木+50%，消耗碎石）/ 杂伐（圆木+15%，副产兽皮）
  - 采石坑：掘脉（碎石+50%，消耗圆木）/ 拾遗（碎石+20%，副产矿铁）
  - 鞣革坊：厚韧（兽皮+60%，狐狸食量+10%）/ 薄削（兽皮+20%，持续转化兽皮为铜钱）
  - 锻造炉：烈焰（矿铁+60%，消耗圆木）/ 巧工（矿铁+25%，矿铁造价-15%）
  - 储藏窖：深窖（上限翻倍）/ 霜藏（野莓上限+50%，寒冬产量+10%）
  - 藏书阁：穷卷（学识+50%，卷轴+30%）/ 秘阁（学识上限翻倍，学识+15%）
  - 灵狐祠：福佑（满意度+3%/座）/ 引灵（符咒+40%，灵术消耗-20%）
- **职业天赋**（7 种，需图纸激活，无数量门槛，不可撤销）：
  - 采集者：勤爪（产量+30%，多消耗野莓）/ 轻手（产量+15%，手动采集+50%）
  - 伐木工：老斧（+40%）/ 兼顾（+15%，副产碎石）
  - 矿工：稳镐（+40%）/ 探脉（+15%，副产矿铁）
  - 猎手：循迹（兽皮+50%）/ 哨眼（兽皮+20%，远行奖励+10%/猎手）
  - 学者：沉思（学识+40%，卷轴+30%）/ 通览（学识+20%，研究费用-10%）
  - 铁匠：锤淬（矿铁+50%）/ 省料（矿铁+20%，锻造炉造价-15%）
  - 商贩：精算（铜钱+50%）/ 广路（铜钱+20%，图纸出现概率提升至60%）
- **商队携带图纸**：4 种商队各有专属图纸池，购买价格含铜钱 + 对应稀有资源
- **UI**：
  - 山外 Tab 商队面板新增图纸商品行
  - 工坊 Tab 新增图纸背包区域（展示已持有图纸，可激活）
  - 营火 Tab 建筑行已激活专精后显示「沃土」等标记
  - 村落 Tab 职业行已激活天赋后显示标记
  - 悬浮面板扩展专精/天赋信息
- **引擎**：
  - `calcR()` 增加专精产量乘数、附加产出、消耗类专精
  - `calcMx()` 增加深窖/秘阁上限翻倍
  - `bp()` 调用 `specCostMul()` 造价修正
  - `rollBlueprint()` 图纸生成（含互斥、资源上限检查）
  - `activateSpec()` / `activateJobTalent()` 激活与自动丢弃
  - 灵术消耗折扣（引灵 -20%）
  - 研究费用折扣（通览 -10%）
  - 存档兼容 `migrate()` 补齐 `blueprints`、`bldSpec`、`jobTalent`
- **Bug 修复**：
  - 霜藏寒冬产量加成从加法改为乘法（0.25→0.275 而非 0.35）
  - 祖灵加成现在包含天赋乘数和天赋额外产出
  - 薄削转化使用独立的消耗/产出速率（兽皮 -0.01/s，铜钱 +0.005/s）
  - 资源速率明细面板完整反映专精/天赋效果（产量乘数、副产、消耗、转化）
  - 满意度明细面板补充福佑、宴席、掌印墙贡献
