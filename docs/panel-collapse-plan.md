# 面板折叠实施方案与检查记录

日期：2026-09-10。范围：本次移动端折叠、跨页签远行显示和遗光日志修正；不改变资源平衡、解锁条件或叙事内容。

当前状态：**已按方案完成并通过本轮验收**。方案先于实现提交在 `05f168c`；引擎/日志 30 项、Chromium 界面 13 项测试通过。详细结果见 [验证记录](validation.md)。

## 一、实施前检查

- 上传包是 v0.11.x 基线；远端 `13764f9` 已有 v0.12.0 初版折叠等修改。保留远端历史，快进合并，不以旧文件强推覆盖。
- `rAll()` 约每秒更新界面；折叠状态不能只留在被重建的 DOM 上。
- 游戏推进在引擎中，但进行中的远行条只在 `rTC()` 的山外分支生成；需将进度展示移到公共区域，不能再增加一套倒计时。
- 长间隔补算当前减去了一个 tick 且清空小数欠账，存在时间损失；独立验证真实时间与游戏 tick 对齐。
- 初版左右标题是 `div/h3 + onclick`，不支持键盘聚焦，没有 `aria-expanded`；每次切回另一页签还会覆盖该页签的折叠偏好。
- 手机端左右栏仍受 160px 高度上限限制，有嵌套滚动；中栏必须保持自然高度，否则折叠后日志不能上移。
- 遗光发现与见闻已有专用色，但远行奖励汇总仍可能走 `important`，离线暂存又统一按 `echo` 输出，需统一所有获得途径。

检查结论：沿用现有三栏和白底文字风格，采用下面的局部改法；不做新框架、列重排或存档大改。**本方案先提交，再实施；最终以回归结果关闭清单。**

## 二、结构与交互

```text
game
├── left-panel
│   ├── 资源标题按钮（始终可见）
│   └── left-body：狐狸村民 + 资源
├── center-panel
│   ├── 各页签按钮（始终可见）
│   └── center-body（由当前页签折叠状态控制）
│       ├── 公共远行进度区域（无队伍时隐藏）
│       └── tc：当前页签的操作内容
└── log-panel
    ├── 谷中见闻标题按钮（始终可见）
    └── log-list
```

1. 点击资源或见闻标题，切换该面板。使用原生 `button`，支持触屏、Enter、空格；显示「收起 / 展开」，同步 `aria-expanded` 和 `aria-controls`。
2. 点击当前页签折叠/展开，点击其他页签切换；营火、村落、工坊、研究和山外分别记忆状态。默认全展开，切回时不强行清空该页签的偏好。
3. 中栏折叠隐藏整个 `center-body`，包括公共远行条，避免折叠后仍被进度区域占高。切换到展开的页签时，直接从 `G.expeditions` 显示最新进度。
4. `hidden` 真正移除内容占高；不使用 `visibility:hidden`、固定占位高度或移动列位置。展开控件不能放在被隐藏的内容中。
5. 折叠仅影响展示。定时器、生产、远行返回、自动存档和日志记录全部继续运行；展开时刷新当前值。

## 三、响应式与存储

- **手机 ≤860px**：资源 → 操作 → 见闻单列自然排布，取消左右栏 160px 上限与内部滚动；折叠资源和当前页签后，见闻紧接标题上移。补足窄屏按钮/文本换行，避免横向溢出。
- **桌面 >860px**：保持资源 200px、日志 230px、中栏弹性布局；折叠只隐藏内部内容，三列的 x 坐标、宽度和列顺序不变。
- 继续使用 `fhFold = {res, log, tab:{b,v,c,r,w}}`。从旧数据只接收已知键与布尔值，坏 JSON、异常字段或 localStorage 不可写时回退为默认状态，不阻断游戏。
- 不将 UI 偏好写进 `G` 或存档码。刷新恢复偏好，游戏导入不冲掉折叠偏好。
- 避免每秒替换未变化的页签按钮，防止键盘焦点丢失；公共进度条复用 DOM，不为显示创建额外计时器。

## 四、遗光日志

- 所有实际获得遗光的日志使用 `remnant` 专用样式，保持与资源面板一致的暗金色。
- 普通发现与固定 +1 事件在末尾显示 `（遗光 +1）`；远行如因现有倍率获得更多，则显示实际 `+N`，不能为了统一文案谎报数量或改变奖励。
- 非遗光奖励保持原有颜色。含多种资源的汇总将遗光奖励放在末尾。
- 离线暂存保留日志类别，并兼容旧存档中的纯字符串队列；不通过在渲染阶段再发奖励来修复颜色。

## 七、布局测量结果

- 390px 测试村落：谷中见闻顶部从展开时约 1505.55px，移动到仅收起资源时约 1013.05px；再收起营火内容后约 165.05px。收起中栏高 69px，文档宽度保持 390px。
- 1440px 桌面：折叠前三列 x 为 0 / 200 / 1210px，宽度为 200 / 1010 / 230px；折叠后相同。高度可随内容缩小，不将其他列挪来填空。
- 测试为真实 Chromium 下的视口/触屏与计时模拟，不等同于 iOS 真机或其他浏览器认证。
