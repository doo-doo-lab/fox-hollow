```sh

node --check js/engine.js
node --check js/ui.js
node --test tests/*.test.cjs
python tests/browser_test.py
python tests/capture_ui.py
git diff --check
```

结果：**30 项引擎/日志测试、13 项 Chromium 界面测试通过**；脚本语法检查与 Git 空白检查通过。界面测试同时监听 JS 异常和 HTTP 资源加载失败，两者均无报告。
