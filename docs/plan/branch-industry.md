## 三、能量系统

能量不是资源，是**产消平衡值**。每秒产出 - 每秒消耗 = 净能量。

- 净能量 ≥ 0：一切正常
- 净能量 < 0：所有吃能量的建筑产出按缺口比例衰减（猫国同机制）

## 四、污染机制（硬惩罚）

工业建筑每秒增加污染，治理建筑每秒减少污染。

### 惩罚阶梯

| 污染值 | 惩罚 |
|--------|------|
| 0-30 | 无 |
| 31-60 | 幸福度-10%, 野莓产出-15% |
| 61-100 | 幸福度-25%, 野莓产出-30%, 狐狸上限-2 |
| 101-150 | 幸福度-40%, 野莓产出-50%, 狐狸上限-5, 商队-20% |
| 150+ | 幸福度-60%, 野莓产出-70%, 狐狸上限-8, 研究-30%, 灰雾事件 |

### 烟囱机制

不减少污染，但提高"豁免阈值"。每座烟囱让惩罚阶梯整体右移 50 点。3 座烟囱 = 污染 150 以内无惩罚。治标不治本——污染持续涨，烟囱有上限。

### 灰雾事件（污染 150+）

随机触发，类似冬季熊袭击。可能导致：狐狸生病（-1 人口）、建筑损坏、资源损失。

### 核心博弈

- 多造工业建筑 → 产出爆炸 → 污染飙升 → 必须造治理建筑
- 治理建筑吃资源和建造位 → 挤占工业建筑空间
- 烟囱是短期方案，净化池/风力塔/净林是长期方案

## 十二、执行顺序（排期）

> 原则：**先框架后内容，先经济后系统，每批可独立测试发布**。
> 对应 roadmap：v0.20 工业化上半（批 0-2），v0.21 工业化下半（批 3-4），太空（批 5-7，版本待定）。
> ⚠️ 所有新名字均为占位，每批动工前需先过用户命名审核（参照 v0.14+文本审核清单 流程）。

### 批 0：横切框架（无新内容，纯引擎/UI 基建）
1. **能量系统**：产消平衡值（非资源），净能量 < 0 时按缺口比例衰减耗能建筑产出（猫国同机制）
2. **污染系统**：隐性累积 +/s、-/s，5 档惩罚阶梯（满意度/野莓/人口上限/商队/研究），烟囱豁免阈值机制
3. **造物页签「进阶」面板**：升级系统 UI 框架（一次性购买、永久生效、6 分类）
4. **灰雾事件**：接入现有山谷见闻事件框架（污染 150+ 触发）
5. 验收：框架空转不影响现有平衡（无工业建筑时能量=0/污染=0）

### 批 1：A 阶段 煤钢时代（经济基础）
1. 资源：煤、钢、钢板、混凝、齿轮（5 囤积）
2. 研究 6：深掘术 → 冶钢 → 精工/锻压/混凝/治污
3. 建筑 2+2：矿坑、高炉；钢仓（存储）、烟囱（治理，可后置到批 2）
4. 配方 4：炼钢、铸齿轮、压钢板、烧混凝（全部接入 v0.10 自动制作体系）
5. 职业 2：深层矿工、炉匠（自动炼钢岗，参照猫国工程师：人数 ≤ 高炉数）
6. 升级 20（A 阶段全量）
7. 验收：纯手动/自动混合玩法下煤钢链无死锁；污染首次可感知（31-60 档）

### 批 2：B 阶段 油火时代（能量+污染博弈成型）
1. 资源：火油、油桶（消耗品→火油上限+10）、图纸（⚠️ 与 v0.12 专精图纸系统命名冲突，需改名）
2. 研究 10：汲液 → 蒸汽原理 → 内燃术/图纸学 → 流水线；油储学、传动学、通途、清风、油气学
3. 建筑 5+2：油井、油缸、蒸汽机房、内燃机、工厂；净化池、风力塔（治理）
4. 配方 3：提炼火油、铸油桶、绘图纸
5. 职业 3：钻井工、机师、工程师
6. 铁路（商队+8%、远行×0.8——接入现有商队/远行系统）
7. 升级 28（B 阶段全量，含自动化类 3 个）
8. 验收：能量首次出现负值场景；污染 61-100 档惩罚可玩

### 批 3：C 阶段 精金时代
1. 资源：寒钛、合金、概要、钛构件、混凝柱
2. 研究 12：煅烧 → 观星/精炼 → 精构/重筑/系统论；回转、流体力学、合金学、模块工程、自动化、望远精修
3. 建筑 4+1：煅烧炉、精炼厂、望远台、铁路已建；净林（治理）、钛库（存储）
4. 配方 4：锻合金、编概要、铸钛构件、灌混凝柱
5. 职业 2：精炼师（全局被动）、星图线预备
6. 升级 30（C 阶段全量）
7. 验收：多耗能建筑并存时能量调度有决策感；星图开始积累
