## Context

游戏当前 v0.13.5 处于"村庄阶段"功能完整但**中后期内容耗尽**。用户希望扩展到**社会模拟级深度**（猫国规模 + 100 小时单 path），并且**强调玩家持续做决策的体感**——不是攒资源等通关，而是不断在治理、文化、宗教、玄学、生产、外交各个维度做小决定。

## 最新决议（2026-04-29，v0.14 启动前）

### 拍板 1：风俗不是资源，是 UI 页签
- 「风俗」**不再是数值资源**（取消 `state.r.custom`）
- 风俗 = UI 页签，下挂习俗（v0.14.0 设计 11，v0.14.1 实施 10），每习俗用现有资源（圆木、染丝、果酒、墨锭、古币、兽皮、卷轴等）激活
- 顶部显示统计「已激活习俗：X / 10」（纯展示无机制）
- 取消语义别扭：原 plan「囤积风俗 → 花光换政变」画面问题解决

### 拍板 2：议事录加「每年开年 +20」基础值
- 解决议事录瓶颈：原 plan 议事录稀缺会引导玩家「攒一笔大改」违反「持续做小决策」
- 新设计：每年开年自动 +20（脱离议事堂数量），保底玩家年年能微调中等政策
- 议事堂保留为加成系数（0.0005/s/座）+ 季节投票 +1-3
- 撤销政策回收 70% **不实施**（防套利复杂度过高）

### 拍板 3：改宗 / 改政体代价由议事录承接
- 原 plan「改宗 ×300 风俗」「改政体 ×500 风俗」→ 全部用议事录替代
- 改宗（v0.18）：议事录 ×150 + 古币 ×50 + 虔诚归零
- 改政体（v0.16）：议事录 ×300 + 古币 ×100
- 议事录承接所有"改革"成本，玩家预期清晰

### 拍板 4：细化范围 = 仅 v0.14
- 本次仅细化 v0.14（风俗页签 + 习俗 + 苍风岭/枯风口）到可实施级（原"苍风岭"v0.14.1 改名"枯风口"）
- v0.15-v0.16 等 v0.14 落地玩家反馈后再细化（避免提前细化做无用功）

### 拍板 5（追加，2026-04-29 v0.14.1 后）：v0.15 主题位移
- 原 v0.15 主题"节气与节庆"调整为**"文化经济循环"**（详见 [docs/plan/v0.15-plan.md](docs/plan/v0.15-plan.md) R2）
- 原因：v0.14 落地后暴露的核心痛点是"染丝/果酒/墨锭无消耗"+"香料/丝帛获取瓶颈"+"商队/图纸概率元加成缺失"——比节气节庆更紧迫
- **24 节气微事件** → 推迟至 v0.19，与玄学·节气玄解一体设计
- **4 大节庆**（春耕祭/夏篝火/秋收宴/年祭）→ 被节令系统（每季手动选择消耗文化品换加成）+ 盈库灵术替代
- **节庆场建筑 + 节庆典制研究** → 取消（节令 + 文化灵术 + 建筑维持已足够创造文化资源持续需求）
- 新主题包含：节令系统、3 文化灵术（盈库/双工/墨契）、月歌台/艺工坊维持、香料 5 路径、丝帛 3 路径、商队/图纸概率元加成、UI 信息渐进展示修复
- 拆分实施：v0.15.0（核心循环）→ v0.15.1（辅助系统）

### 远期占位标记（待 v0.16+ 实施时统一处理）
- v0.20-21 工业化触发条件「学识 800 + 风俗 200 + 矿铁 500」中"风俗 200"原为资源阈值，需改为"已激活习俗 ≥ 12"或同类条件

## 设计原则（v2，含用户最新反馈）

1. **多轴并行**：风俗 / 政体 / 政策 / 宗教 / 玄学 / 工业化 / 自然主义 不互锁
2. **互斥点收敛在"主选"**：政体（**可改但代价大**）、主神（改宗代价大）、终局（1 选多）
3. **决策密度高**：玩家在游戏全程不断做小决策，不是几次大决策
4. **政策非一次性**：参考猫国 + 现实政治分支，**多个政策域 × 每域多选项 = 几十个决策点**，部分可改
5. **每步对数值影响可控**：新资源/建筑维持 k=1.12 通胀曲线
6. **小步快跑**：分版本递进
7. **命名禁区**：避免与猫国相同特有名；通用术语可用
8. **占位标记**：所有未审核命名以 `「占位：X」` 标注
9. **100 小时单 path 目标**：覆盖 ≥100 游戏年≈80 小时实时

## 决策密度框架（核心新增）

让玩家"运营社会"的感觉，关键是**全程持续决策**。游戏中决策点分布：

| 决策类型 | 频次 | 影响 |
|---|---|---|
| **远行抉择事件** | 远行返回时 30% 概率（已有）| 短期 buff/资源 |
| **节令选择**（v0.15） | 每年 4 次 | 季节性 buff（染丝/果酒/墨锭三选） |
| **文化灵术施放**（v0.15） | 每季 0-3 次 | 资源上限/工坊产出/研究费用 |
| **节气解读**（v0.19）| 每年 24 次 | 微 buff/debuff |
| **占卜解签**（v0.19）| 每年 1 次 | 一年方向预判 |
| **政体选定** | 一次（v0.16），**可改但代价大** | 整体框架 |
| **政策调整** | **20+ 个政策域 × 各 2-3 选项**（v0.16-0.17） | 持续微调，常需重新评估 |
| **主神选定** | 一次（v0.18），**可改但代价大** | 信仰路线 |
| **仪式施放**（v0.18）| 每季多次 | 中期 buff |
| **种族外交**（v0.24）| 商队来访时 | 关系递进 |
| **生产路线** | 一次（v0.20+）但**两条可双修** | 终局走向 |
| **应灾决策**（v0.20+）| 灾害发生时 | 应对方式 |
| **建筑专精激活** | 已有 16 选择 | 永久（已实装） |

总决策点估计 **~80-120 次/单 path**，覆盖 100 小时 = 平均每 1 小时玩家做 1 个有意义的决策。

## 政体 + 政策的全面展开（v0.16-0.17 重设计）

这是用户最强调的层面。完整框架：

### 政体（v0.16）—— 可改但代价大

**6 政体（占位）**：长老议会 / 公议会 / 商道议会 / 谷无主 / 隐居宗 / 武德同

**改政体机制**（关键改动）：
- 改政体需消耗 **古币 ×100、议事录 ×300**（**风俗代价已取消**），1 季全村满意度 -20%
- 累计改 1 次：解锁**革新者**成就；改 ≥3 次：触发**动荡之村**事件

### 政策机制细节
- 每条政策都有数值影响（±5-15%）
- **大部分政策可改**，调整需消耗议事录（5-30 不等，视政策影响力）
- 部分政策有冷却（如改"通商"后 5 年不能再改）
- 政策**激活后立即生效**，无过渡期
- 政策之间**有冲突**：例如 "排教" + "政教合一" 冲突，必须二选一
- **政策面板** UI：列出所有已解锁政策域，标注当前选项 + 修改按钮

### 议事录资源 —— 占位名

**`「占位：议事录」`** (`council`)
- 来源：
  - **每年开年 +20 基础值**（脱离议事堂数量，保底产出）
  - 议事堂被动 +0.0005/s/座（系数加成）
  - 政体专属议事事件 +5
  - 季节投票活动 +1-3
- 消耗：
  - 政策切换 5-30
  - 政体改革 ×300
  - 改宗（替代风俗代价）×150
  - 外交协议 50-100
- **平衡评估**：基础保底 +20/年 让玩家年年能微调政策（持续做小决策），议事堂加成决定改大革命的速度（稀缺感保留但不阻塞日常）

## 宗教深化（v0.18，扩展决策密度）

不只是"6 神 1 选"，每神有内部派系/仪式选择。

### 主神选定（占位）：山神 / 月狐 / 篝火神 / 雾中无名 / 祖灵集合 / 第六神

### 每神的决策点（v0.18 关键扩展）

| 决策维度 | 内容 |
|---|---|
| **教派**（每神 2-3 派） | 例：山神有"原岩派"和"风化派"，月狐有"望月派"和"暗夜派"——内部选择影响 buff 偏向 |
| **仪式**（每神 5-8 个） | 玩家选择何时施放、消耗资源换 buff |
| **神迹应对**（神迹事件触发时 2-3 选项）| 如"山神显灵，要不要献祭一只狐狸"等戏剧选择 |
| **改宗**（一次性大选）| 改主神代价：议事录 ×150、古币 ×50、虔诚归零（**风俗代价已取消**）|

### 总决策点（v0.18）：
- 1 主神选 + 1 教派选 + 30+ 仪式频次选 + 18-30 神迹应对 = **~50-80 决策点**

## 玄学深化（v0.19，每年大量小决策）

不只是"4 子系统开"，每个子系统玩家持续做选择。

### 子系统的决策密度

| 子系统（占位） | 决策频次 |
|---|---|
| **`「占位：占卜」`** | 每年开年摇签 → 解读，玩家选信不信、用不用、给哪个建筑加成 |

| **`「占位：命数」`** | 命运卡每年抽 1 张，玩家可花资源**改命**（消耗灵气 + 古币）|
| **`「占位：节气玄解」`** | 24 节气可解读吉/凶/平 → 选择是否绑定主动仪式（每节气决策点 ×24/年）|

**每年新增 ~30-40 玄学决策**

## 工业化深化（v0.20-21，环境政策与污染权衡）

### 关键新概念：污染（占位）

工业化建筑产生**`「占位：污染」`**资源（负值满意度来源）。玩家通过：
1. 工艺/建筑减污染
2. 环境政策（"治理"/"严控"）减污染但增资源消耗
3. 容忍污染换更高产量
